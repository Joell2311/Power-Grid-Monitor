# Objetivo

O COI Monitor é um sistema de apoio à operação de redes de distribuição de energia elétrica.

Seu objetivo é fornecer ao operador uma visão completa da rede em tempo real, permitindo analisar ocorrências, avaliar impactos operacionais, simular manobras, recomendar sequências de recomposição e acompanhar indicadores operacionais.

O sistema foi projetado utilizando uma arquitetura baseada em entidades da rede elétrica, separando dados cadastrais, estado operacional, regras de negócio e interface gráfica.

Todo o sistema possui uma única fonte de verdade para cada informação, evitando duplicidade de dados e inconsistências.
